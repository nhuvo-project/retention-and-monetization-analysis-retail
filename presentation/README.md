# Presentation Deliverables

This folder contains the final consulting-style presentation developed from the analysis of The Look ecommerce dataset.

## Included File
- `full_case_deck.pdf` → end-to-end business case presentation covering:
  - revenue diagnosis
  - customer retention analysis
  - repeat purchase behavior
  - return impact analysis
  - category monetization performance
  - inventory-demand alignment
  - strategic recommendations
- `analytical_appendix.pdf` → providing methodology, analytical reasoning, intermediate findings, and additional analytical breakdowns

## Presentation Objective
Identify the primary factors constraining sustainable ecommerce growth and provide data-driven recommendations to improve retention and monetization performance.
