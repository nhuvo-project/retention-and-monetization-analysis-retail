# Data Dictionary

| Column Name | Description |
|---|---|
| order_item_id | Unique identifier for each transaction line item |
| order_id | Unique customer order identifier |
| user_id | Unique customer identifier |
| category | Product category |
| sale_price | Final transaction price paid by customer |
| retail_price | Original listed product price |
| order_status | Standardized transaction status (Completed, Returned, In Progress) |
| discount_percentage | Relative discount applied to the product |
| discount_tier | Discount intensity classification |
| customer_type_lifetime | Customer segmentation based on lifetime order count |
| order_month | Monthly cohort used for retention analysis |
